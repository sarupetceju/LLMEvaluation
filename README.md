# LLMEvaluation

This repository describes different mertics available for LLM evalutaion. Evaluating LLMs’ performance is slightly different from traditional ML models, as very often there is no single ground truth to compare against. MLflow provides an API mlflow.evaluate() to help evaluate your LLMs. I have also used Dagshub for Visualization and tracking. DagsHub tracks model performance metrics, experiment results, and allows for easy comparison of LLMs over time
